Guía de publicación de entradas

Tu servidor local Apache en Linux MAX 12 · Geany + HTML + JSON + JavaScript

Objetivo: añadir una publicación nueva a la página principal sin modificar index.html ni entradas.js. El archivo JSON contiene el catálogo de entradas y cada HTML contiene su texto completo.

1Abrir el editor Geany

Inicia Geany desde el menú de aplicaciones de MAX o ejecuta en un terminal:

geany

Abre tu copia de /home/madrid/entradas.json mediante Archivo → Abrir.

2Modificar el JSON para registrar una nueva entrada

Añade un objeto dentro de la lista de entradas.json, separado del anterior mediante una coma:

{
  "titulo": "Mi nueva publicación",
  "fecha": "2026-11-15",
  "descripcion": "Descripción breve de mi publicación.",
  "url": "publicaciones/nueva-entrada.html"
}

Conserva los corchetes [ ] del archivo y las entradas anteriores. Cada objeto lleva coma de separación excepto el último. La fecha sigue el formato AAAA-MM-DD. El nombre de la URL debe coincidir exactamente con el archivo HTML que crearás.

3Guardar el JSON en tu carpeta personal

En Geany, guarda el archivo actualizado como:

/home/madrid/entradas.json

Si ya está abierto desde esa ruta, basta con Archivo → Guardar (Ctrl+S).

4Copiar el JSON a la raíz de Apache

Abre un terminal y ejecuta:

sudo cp /home/madrid/entradas.json /var/www/html/entradas.json

Comprueba el catálogo servido por Apache en http://localhost/entradas.json.

5Crear el nuevo fichero HTML en Geany

Selecciona Archivo → Nuevo y escribe el contenido completo de tu publicación. Puedes usar esta plantilla:

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Mi nueva publicación</title>
</head>
<body>
  <h1>Mi nueva publicación</h1>
  <p>Aquí escribo el contenido de la entrada.</p>
  <a href="../index.html">Volver al inicio</a>
</body>
</html>

Guárdalo en tu carpeta personal con el nombre indicado en el JSON:

/home/madrid/nueva-entrada.html

6Copiar el HTML al directorio de publicaciones de Apache

Ejecuta:

sudo cp /home/madrid/nueva-entrada.html /var/www/html/publicaciones/

Comprueba la página en http://localhost/publicaciones/nueva-entrada.html.

7Refrescar la página principal

Abre http://localhost/ en Firefox y pulsa Ctrl+F5. La nueva entrada aparecerá en Últimas publicaciones, ordenada por fecha. Haz clic en Leer publicación para abrir su HTML.

Si el enlace da error 404, comprueba el nombre del archivo y la ruta url en el JSON. Si la entrada no aparece, comprueba que el JSON sea válido y que hayas copiado la versión actualizada.

Recuerda: para cada nueva publicación modificas entradas.json y creas un nuevo archivo HTML. No necesitas tocar entradas.js ni reiniciar Apache.
