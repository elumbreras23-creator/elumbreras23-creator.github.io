1. ¿Qué hemos construido?

Una página principal que muestra una lista de publicaciones. Los datos de esa lista no están escritos dentro de index.html: se guardan en entradas.json. Cuando Firefox abre la página, entradas.js lee esos datos, los ordena y crea los elementos HTML que ves en pantalla.

Idea clave: para añadir una publicación normal, no hace falta cambiar index.html ni entradas.js. Se crea la página de la publicación y se registra en el JSON.

  1. Firefox solicita http://localhost/.
  2. Apache entrega la página principal, que enlaza el archivo entradas.js.
  3. Firefox ejecuta JavaScript y este hace una segunda petición HTTP para obtener entradas.json.
  4. El navegador convierte el JSON en objetos JavaScript, los ordena por fecha y construye los elementos visibles.
  5. Cuando pulsas «Leer publicación», Firefox solicita el HTML indicado por el campo url.
Apache no interpreta ni ejecuta este JavaScript: lo sirve como archivo. En este modelo, el código se ejecuta en Firefox.

4. JSON: la fuente de datos

JSON significa JavaScript Object Notation. Es un formato de texto estructurado, muy utilizado para intercambiar datos. Aquí contiene un array (los corchetes) de objetos (las llaves).

[
  {
    "titulo": "Mi primera publicación",
    "fecha": "2026-11-15",
    "descripcion": "Estoy aprendiendo HTML, JSON y JavaScript.",
    "url": "publicaciones/entrada1.html"
  },
  {
    "titulo": "Cómo funciona mi web",
    "fecha": "2026-11-15",
    "descripcion": "Explicación de JSON y JavaScript.",
    "url": "publicaciones/entrada2.html"
  }
]

Reglas importantes

  • Las claves y los textos van entre comillas dobles.
  • Los objetos se separan mediante comas; el último no lleva coma.
  • La fecha usa AAAA-MM-DD, lo que facilita la ordenación como texto.
  • La URL es una ruta relativa a la página principal y debe apuntar a un HTML existente.
  • JSON no es una base de datos: es un archivo de datos que editamos y copiamos al servidor.

5. JavaScript: cómo funciona cada instrucción

Este es el código que hemos utilizado como modelo para entradas.js. Si has modificado el archivo después, puede haber diferencias con tu versión real.

fetch("entradas.json")
  .then(respuesta => {
    if (!respuesta.ok) {
      throw new Error("No se pudo cargar entradas.json");
    }
    return respuesta.json();
  })
  .then(entradas => {
    const contenedor = document.getElementById("lista-publicaciones");
    contenedor.innerHTML = "";

    entradas.sort((a, b) => b.fecha.localeCompare(a.fecha));

    entradas.forEach(entrada => {
      const articulo = document.createElement("article");
      const titulo = document.createElement("h3");
      const fecha = document.createElement("p");
      const descripcion = document.createElement("p");
      const enlace = document.createElement("a");

      titulo.textContent = entrada.titulo;
      fecha.textContent = entrada.fecha;
      descripcion.textContent = entrada.descripcion;
      enlace.textContent = "Leer publicación";
      enlace.href = entrada.url;

      articulo.append(titulo, fecha, descripcion, enlace);
      contenedor.appendChild(articulo);
    });
  })
  .catch(error => {
    console.error("Error cargando publicaciones:", error);
    document.getElementById("lista-publicaciones").textContent =
      "No se pudieron cargar las publicaciones.";
  });

fetch("entradas.json")

Realiza una petición HTTP desde Firefox a Apache para recuperar el archivo JSON. Es asíncrona: el navegador no tiene que detener toda la página mientras espera la respuesta.

.then(...) y respuesta.json()

then indica qué hacer cuando se resuelve una promesa. respuesta.ok permite detectar respuestas HTTP fallidas, como 404. respuesta.json() lee el cuerpo de la respuesta y lo convierte en datos JavaScript.

const y getElementById()

const declara una referencia que no reasignaremos. document.getElementById("lista-publicaciones") busca el contenedor HTML por su identificador.

innerHTML = ""

Vacía el contenido anterior del contenedor, incluido el mensaje de prueba «Aquí aparecerán las publicaciones».

sort() y localeCompare()

sort ordena el array. Con fechas escritas como AAAA-MM-DD, la comparación de cadenas permite ordenar de más reciente a más antigua. Si dos publicaciones tienen la misma fecha, este ejemplo no define una prioridad adicional.

forEach()

Recorre todos los objetos del array. En cada vuelta, la variable entrada representa una publicación distinta.

createElement(), textContent y href

createElement crea etiquetas HTML en memoria. textContent coloca texto sin interpretarlo como HTML; href establece el destino del enlace. Finalmente, append y appendChild insertan los elementos en la página.

.catch()

Captura errores de la cadena de promesas y muestra un mensaje para evitar que el usuario vea simplemente una sección vacía.

6. El DOM: la conexión entre HTML y JavaScript

El DOM (Document Object Model) es la representación de la página que maneja el navegador. JavaScript puede localizar nodos y crear otros nuevos.

<section id="publicaciones">
  <h2>Últimas publicaciones</h2>
  <div id="lista-publicaciones">
    <p>Aquí aparecerán las publicaciones.</p>
  </div>
</section>

<!-- Al final del body -->
<script src="entradas.js"></script>

Cuando JavaScript ejecuta getElementById, obtiene el div. Después inserta en él un article por cada objeto JSON. Por eso la página cambia sin que tengas que escribir manualmente las tarjetas en index.html.

Colocamos el script al final de body para que el contenedor ya exista cuando se ejecute. Otra posibilidad sería cargar el script con defer desde head.

En este proyecto no necesitas PHP ni MariaDB para mostrar las publicaciones. Tampoco hay un panel de edición: el contenido se prepara con Geany.

8. Proceso de publicación habitual

  1. Abre Geany.
  2. Edita /home/madrid/entradas.json y añade un nuevo objeto con título, fecha, descripción y URL.
  3. Guarda el JSON en tu carpeta personal.
  4. Cópialo al servidor con el primer comando.
  5. Crea en Geany el HTML completo de la nueva entrada, por ejemplo /home/madrid/entrada3.html.
  6. Cópialo a la carpeta publicaciones con el segundo comando.
  7. Abre http://localhost/ y pulsa Ctrl + F5.
sudo cp /home/madrid/entradas.json /var/www/html/entradas.json
sudo cp /home/madrid/entrada3.html /var/www/html/publicaciones/

Comprueba el resultado abriendo http://localhost/entradas.json y, después, http://localhost/publicaciones/entrada3.html.

El nombre indicado en el campo url debe coincidir exactamente con el archivo copiado a publicaciones/, incluidas mayúsculas y minúsculas.

10. Posibles mejoras

  • Crear una plantilla HTML común para todas las publicaciones.
  • Añadir estilos CSS a las tarjetas y fechas más legibles.
  • Mostrar únicamente las cinco entradas más recientes.
  • Añadir categorías, etiquetas o un buscador.
  • Más adelante, crear un formulario con PHP para publicar desde el navegador, si quieres evitar la edición manual.
Resumen: HTML define dónde se muestra el contenido; JSON guarda los datos; JavaScript lee, ordena y construye las entradas; Apache sirve los archivos; Firefox ejecuta JavaScript y presenta el resultado.
